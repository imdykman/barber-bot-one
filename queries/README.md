# 📊 Полезные SQL-запросы для салона "Ножницы&Ко"

## Как использовать

1. Откройте **DB Browser for SQLite**
2. Откройте базу данных: `database/barber.db`
3. Перейдите на вкладку **"Execute SQL"**
4. Нажмите **"Load SQL"** и выберите нужный файл
5. Нажмите **▶️ (Execute)** или **Ctrl+R**
6. Результаты появятся внизу

## Список запросов

### 📅 today-bookings.sql

Все записи на сегодня с детальной информацией:

- Время записи
- Имя клиента и телефон
- Мастер
- Услуга
- Цена

### 💰 monthly-stats.sql

Статистика за текущий месяц по мастерам:

- Количество записей
- Общая выручка
- Сортировка по убыванию выручки

### 🔥 popular-services.sql

Топ-10 самых популярных услуг:

- Название услуги
- Количество записей
- Средняя цена

### new-clients.sql

Новые клиенты (кто был 1 раз или ещё не был):

- Имя и телефон
- Количество визитов
- Сортировка по дате последнего визита

### 📊 master-workload.sql

Загруженность мастеров:

- Мастер и филиал
- Количество записей за месяц
- Выручка за месяц
- Сортировка по количеству записей

## Примеры использования

### Ежедневная проверка

Каждое утро открывайте `today-bookings.sql`, чтобы увидеть записи на сегодня.

### Еженедельный отчёт

Раз в неделю запускайте `monthly-stats.sql` и `master-workload.sql` для анализа работы.

### Поиск новых клиентов

Используйте `new-clients.sql` для выявления клиентов, которым можно предложить скидку на повторный визит.

## Добавление своих запросов

Если у вас есть полезный запрос:

1. Сохраните его в эту папку с понятным именем (на латинице)
2. Добавьте описание в этот README
3. Закомментируйте в файле, что делает запрос

## Примечания

- Все даты в формате `YYYY-MM-DD`
- Статусы записей: `confirmed` (подтверждено), `cancelled` (отменено), `completed` (завершено)
- Для массовых изменений используйте транзакции (BEGIN TRANSACTION; ... COMMIT;)
