# Служебные скрипты

Эта папка содержит скрипты для инициализации и обслуживания базы данных.

## 📅 init-salon-schedule.js

**Назначение:** Инициализация таблицы `salon_schedule` с дефолтным графиком работы салона.

**Когда использовать:**

- При развертывании проекта на новом сервере
- При сбросе базы данных
- При необходимости вернуть дефолтный график (Пн-Вс, 10:00-20:00)

**Запуск:**

```bash
node scripts/init-salon-schedule.js
```
