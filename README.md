# ✂️ Ножницы & One — Max-бот для онлайн-записи

Полнофункциональный бот для управления записями в салоне красоты "Ножницы & One". Поддерживает клиентский интерфейс записи, мощную админ-панель, гибкое управление расписанием и автоматические уведомления.

## 🚀 Возможности

### 👤 Для клиентов

- 📅 Пошаговая онлайн-запись: выбор мастера → услуги → даты → времени.
- 📱 Быстрая отправка контакта через MAX API для подтверждения.
- 📋 Просмотр активных записей и истории посещений.
- ❌ Возможность самостоятельной отмены записи с автоматическим уведомлением админа.

### 👑 Для администраторов

- 📝 Создание записи за клиента вручную.
- 📊 Просмотр записей на сегодня, статистика и фильтрация всех записей.
- 👨‍💼 Управление мастерами: добавление, активация/деактивация, привязка услуг с индивидуальной ценой и длительностью.
- 💈 Управление услугами: добавление, редактирование, деактивация.
- ⚙️ **Гибкое управление расписанием:**
  - Базовый график работы всего салона (часы начала/окончания, выходные дни).
  - Разовые выходные для всего салона (праздники, корпоративы).
  - Индивидуальные перерывы для конкретных мастеров на определенные даты.
- 📥 Экспорт записей в CSV (Excel) с отправкой на email администратора.

### 📧 Уведомления

- Автоматическая отправка email админу при создании новой записи.
- Автоматическая отправка email админу при отмене записи клиентом.

## 🛠️ Технологический стек

- **Runtime:** Node.js
- **Framework:** `@maxhub/max-bot-api` (MAX / VK Bot API)
- **База данных:** SQLite (`better-sqlite3`)
- **Почта:** `nodemailer` (SMTP)
- **Веб-сервер:** Express (для API и веб-версии записи)

## 📂 Структура проекта

```text
barber-bot-one/
├── bot.js                 # Точка входа бота

├── database/

│   ├── client.js          # Обработчики callback-кнопок клиента
│   └── messages.js        # Обработка текстовых сообщений и контактов
```

Инициализация базы данных:
База данных SQLite создается автоматически при первом запуске. Таблицы инициализируются с демо-данными (график салона Пн-Вс 10:00-20:00).

# Запуск бота

node bot.js

# Запуск веб-сервера (в отдельном терминале)

node server.js

Ключевые таблицы базы данных
masters — мастера салона.
services — справочник услуг.
master_services — привязка услуг к мастерам с индивидуальной ценой и длительностью.
bookings — записи клиентов (хранит client_name и client_phone напрямую).
salon_schedule — базовый график работы салона по дням недели.
salon_holidays — разовые выходные дни для всего салона.
master_breaks — индивидуальные перерывы конкретных мастеров.
